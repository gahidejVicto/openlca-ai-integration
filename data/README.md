# Données locales

Les sous-dossiers `test/`, `methods/` et `production/` sont volontairement vides dans Git. Ils servent respectivement aux petites bases d'apprentissage, aux méthodes LCIA locales et aux bases réelles ou sensibles. Consultez la [politique de gestion des données](../docs/data-management.md).

> **NE JAMAIS COMMITER ECOINVENT OU UNE BASE `.zolca` DANS CE DÉPÔT.**

Seuls les fichiers `.gitkeep` maintiennent cette arborescence. Placez les données localement : les règles du `.gitignore` les excluent du versionnement.
