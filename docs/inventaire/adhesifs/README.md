# Inventaire ACV — Adhésifs

Ce répertoire documente des produits d'adhésifs réellement utilisés en
ébénisterie (colle contact, colle blanche à bois). Conventions de statut et
de sourçage : voir le [README principal de l'inventaire](../README.md) et le
[README du répertoire panneaux](../panneaux/README.md).
