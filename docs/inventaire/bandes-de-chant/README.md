# Inventaire ACV — Bande de chant (fonction métier, toutes matières)

Ce répertoire regroupe la **fonction métier « bande de chant »**,
indépendamment de la matière (bois véritable, polyester, PVC, PE). Il a été
créé le 2026-09-22 pour documenter les **produits de référence choisis
explicitement par Jérôme**, qui remplacent la logique exploratoire à
plusieurs candidats de la passe précédente (conservée comme contexte
historique dans [`../plastiques/bande-de-chant-candidats.md`](../plastiques/bande-de-chant-candidats.md)).

> [!IMPORTANT]
> **La bande de chant en bois véritable n'est pas un plastique.** Elle est
> néanmoins regroupée ici avec les bandes de chant polyester et PVC parce
> qu'elles répondent toutes à la même fonction métier (habillage de chant
> de panneau) et sont comparées ensemble dans la [synthèse fabricants](../donnees-fabricants-recq36-2026-09-22.md).
> Les conventions de statut et de sourçage sont celles décrites dans le
> [README principal de l'inventaire](../README.md) et le
> [README du répertoire panneaux](../panneaux/README.md).

## Discipline de sourçage renforcée (2026-09-22)

Chaque donnée factuelle est étiquetée selon quatre catégories :

- **FAIT SOURCÉ** — provient directement d'une source citée (URL, organisme,
  date de consultation).
- **CALCUL À PARTIR DE DONNÉES SOURCÉES** — dérivé par un calcul explicite
  à partir de valeurs sourcées ; jamais présenté comme un fait fabricant.
- **INFÉRENCE** — interprétation raisonnable mais non confirmée par une
  source directe ; toujours signalée comme telle.
- **NON TROUVÉ** — absence réelle constatée après recherche, jamais
  comblée par une supposition.
