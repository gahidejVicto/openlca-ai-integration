# Inventaire ACV — Quincaillerie de meuble

Ce répertoire documente des produits de quincaillerie de meuble réellement
vendus au Québec/Canada (coulisses de tiroir, et à terme charnières,
poignées, pieds réglables). Les conventions de statut et de sourçage sont
celles décrites dans le [README principal de l'inventaire](../README.md)
et le [README du répertoire panneaux](../panneaux/README.md) (statuts
✅ / ⚠️ / ❓, règles de traçabilité des sources).

## 📁 Fichiers

| Fichier | Rôle |
|---|---|
| [`coulisse-langevin-forest.md`](coulisse-langevin-forest.md) | Coulisse de tiroir générique sans marque identifiable, distribuée par Langevin Forest (Montréal, QC). |
| [`coulisse-blum-movento.md`](coulisse-blum-movento.md) | Coulisse invisible Blum MOVENTO (référence `760H4000S`, 40 kg), disponible via Richelieu Hardware. |

> [README du répertoire panneaux](../panneaux/README.md#règle-de-correspondance-avec-ecoinvent).
