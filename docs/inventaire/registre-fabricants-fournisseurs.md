## 2. Nomenclature des statuts

Chaque entreprise est qualifiée selon **trois axes indépendants**.

**Rôle dans la chaîne** (ce que fait l'entreprise pour le produit visé) :

| Rôle | Signification |
|---|---|
| **Fabricant** | Fabrication du produit visé établie par une fiche Git sourcée. |
| **Fabricant (selon FR-V0)** | Fabrication affirmée par la feuille de route V0, non encore prouvée dans Git. |
| **Activité selon V-0930 / QWEB-0930** | Seule l'activité notée dans l'Excel est connue (ex. « scierie », « placage ») ; rôle exact à établir. |
| **Fournisseur/distributeur** | Vend ou distribue ; ne prouve pas une fabrication. |
| **Marque** | Nom commercial rattaché à un fabricant/groupe ou à un distributeur ; n'est pas une entreprise distincte. |
| **Fabricant/OEM à déterminer** | Le fabricant réel du produit acheté n'est pas identifié. |
| **Entreprise utilisatrice** | Fabrique/livre des meubles ; interrogée sur ses fournisseurs, pas documentée comme fabricant. |

**Statut documentaire** (ce que Git contient) :

| Statut | Signification |
|---|---|
| **Documenté** | Fiche d'inventaire Git avec sources pour le rôle/produit concerné. |
| **Partiellement documenté** | Fiche Git existante, mais le rôle ou le produit visé n'y est pas couvert, ou seulement comme piste. |
| **Candidat identifié** | Entreprise identifiée (FR-V0, V-0930, QWEB-0930 ou N-0928), sans fiche Git. |
| **À identifier** | Identité incertaine ; aucune fiche avant confirmation. |

**Statut métier** (ce que les échanges métier ont établi) :

| Statut | Signification |
|---|---|
| **Validé métier** | Représentativité pour le marché québécois explicitement confirmée par une validation métier documentée. **Aucune entrée à ce jour.** Ne se déduit jamais de la seule présence dans l'Excel V-0930. |
| **Cité par Vincent — 2026-09-30** | L'entreprise figure dans les notes manuscrites V-0930 : évoquée comme pertinente/candidate, pas formellement validée. |
| **Candidat externe — QWEB** | Ajoutée lors du contrôle QWEB-0930 ; non attribuable à Vincent. |
| **Proposé par Nicolas — 2026-09-28** | Suggestion N-0928. |
| **Non cité le 2026-09-30** | Entreprise déjà au registre (FR-V0 ou fiche Git) absente des notes V-0930 et du contrôle QWEB. L'audio étant perdu, cette absence **ne vaut ni rejet ni validation**. |

> [!NOTE]
> Une même entreprise peut cumuler plusieurs provenances (ex. N-0928 et
> V-0930) ; elles sont toutes conservées dans la colonne Provenance.
