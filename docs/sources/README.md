# Sources et traçabilité

Toute valeur utilisée à l'avenir pour régionaliser un dataset doit pouvoir être reliée à une source. GitHub documente les références, décisions et raisonnements ; il ne sert pas à stocker le contenu propriétaire ou protégé d'ecoinvent.

## Catégories de sources

- ecoinvent ;
- documentation openLCA ;
- littérature scientifique ;
- données gouvernementales du Québec ;
- données gouvernementales du Canada ;
- associations sectorielles ;
- données de fabricants ;
- données primaires d'entreprises ;
- hypothèses internes.

Une hypothèse interne doit être signalée comme telle, justifiée et remplacée par une source plus robuste lorsqu'elle devient disponible.

## Métadonnées à conserver

Pour chaque source importante, conserver si possible :

| Champ | Contenu attendu |
|---|---|
| Titre | Titre exact du document ou du jeu de données |
| Organisme / auteur | Responsable de la publication ou de la donnée |
| Année | Année de publication ou période couverte |
| URL ou référence | Lien public, DOI, cote ou référence bibliographique |
| Date de consultation | Date au format `AAAA-MM-JJ` |
| Périmètre géographique | Québec, Canada, Amérique du Nord ou autre |
| Qualité / représentativité | Limites, technologie, âge, échantillon et adéquation à l'usage |

Les fiches doivent relier chaque paramètre critique, provider retenu et conclusion de représentativité à cette information. Une référence à ecoinvent peut décrire le nom, la version et le raisonnement nécessaires à l'analyse, mais ne doit pas reproduire ou joindre de base, d'archive ou de contenu protégé par la licence.
