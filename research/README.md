# Research

Ce répertoire contient la méthodologie, les templates et les éléments de travail réutilisables qui servent à construire les analyses.

- [`docs/`](../docs/) contient la documentation consolidée et lisible : index métier, fiches analysées, décisions et références.
- [`research/`](./) contient les outils méthodologiques réutilisables, dont le [template d'analyse de dataset](templates/dataset-analysis.md).

Les brouillons utiles doivent devenir traçables avant d'alimenter une conclusion consolidée. Aucune base ACV, archive ecoinvent, donnée propriétaire, export massif openLCA, donnée confidentielle ou donnée soumise à licence ne doit être placée dans `research/` ou commitée dans Git.
